# 🌿 Aruanã Natural

> Site institucional desenvolvido para uma marca de produtos artesanais voltados para autocuidado, aromaterapia e bem-estar.

O projeto foi criado para apresentar os produtos da **Aruanã Natural** de forma visual, facilitar o contato com clientes e criar uma experiência alinhada à identidade da marca.

---

## ✨ Sobre o projeto

A proposta foi desenvolver uma página leve, responsiva e com uma identidade visual inspirada em **natureza, autocuidado e bem-estar**.

Além da apresentação da marca e dos produtos, o site conta com uma área de avaliações dos clientes e um painel administrativo para gerenciamento dos feedbacks.

---

## 🛍️ Funcionalidades

* 🕯️ Apresentação da marca
* 🛒 Catálogo de produtos
* 🔎 Filtros por categoria
* 🌙 Seção de rituais
* ⭐ Avaliações de clientes
* 💬 Carrossel de feedbacks
* 🔐 Painel administrativo
* ☁️ Integração com Supabase
* 📱 Layout responsivo
* 📲 Contato pelo WhatsApp
* 📷 Link para Instagram
* ✨ Animações e efeitos de rolagem

## ☁️ Supabase

O **Supabase** é utilizado para armazenar os feedbacks enviados pelos visitantes e controlar o acesso ao painel administrativo.

O fluxo dos feedbacks funciona assim:

```text
Visitante
    ↓
Envia uma avaliação
    ↓
Supabase
    ↓
Painel administrativo
    ↓
Aprovação
    ↓
Feedback exibido no site
```
